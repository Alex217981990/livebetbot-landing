# LiveBet Bot — Landing

Статический одностраничный сайт для аналитического Telegram-бота **@livebetfootball_bot**.

Live: https://livebetbot.ru

## Структура

```
index.html      главная страница
oferta.html     договор-оферта
privacy.html    политика обработки персональных данных
logo.png        логотип
robots.txt      инструкции для поисковиков
sitemap.xml     карта сайта
```

## Деплой

Авто-деплой на Netlify при каждом push в `main`.

## Стек

Чистый HTML/CSS без зависимостей. Никакой сборки, никакого JS. Один файл = одна страница.
